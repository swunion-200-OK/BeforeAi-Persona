1. 귀사의 무궁한 발전을 기원합니다.

2. 관련
   - 가. 당사 공문 「AI 작업 통제 서비스(BeforeAI) 도입 검토 결과 통보 및 기능·자료 요청」 (한성소프트-구매-2026-1109-01, 2026. 11. 9.)
   - 나. 귀사 기술 지원 담당 보완 설명 회신 (2026. 11. 16. ~ 11. 17.)
   - 다. 당사 내부 재검토 회의 (2026. 11. 18.)

3. 당사는 위 관련 가.의 1차 공문 이후 귀사가 제공한 보완 설명(실행기의 성격 재정의, Tailscale의 용도 구분)을 검토하였습니다. 본 공문은 **1차 공문을 철회하지 않으며**, 보완 설명으로 인해 **완화·조정된 우려 항목**과 **그와 무관하게 여전히 유지되는 필수 조건·신규 확인 항목**을 구분하여 재통보하는 문서입니다. 시범 사용 1순위 후보 선정과 필수 조건 미충족 시 도입 보류 원칙은 변동이 없습니다.

4. 보완 설명에 대한 당사의 이해

   당사는 귀사의 보완 설명을 아래와 같이 이해하였습니다. 이해에 오류가 있으면 회신하여 주시기 바랍니다.

   **가. 실행기의 성격**

   | 번호 | 당사가 이해한 내용 | 명세 근거 |
   | --- | --- | --- |
   | 1 | 실행기는 운영 작업을 대신 수행하는 별도의 무거운 인프라 러너가 아니라, Plan 해시를 스스로 생성하고 Ed25519 서명·nonce를 검증하는 **서명 검증기**임 | 2.3, 2.4, 5.1 |
   | 2 | 승인 envelope은 비대칭키 기반 종단간 암호화(E2EE)로 전달되어 **실행기 공개키로만 복호화**되며, 웹 서비스는 envelope을 열 수 없음 | 2.4, 4.5 |
   | 3 | 검증 6단계를 통과하면 실행기가 **로컬에서 웹쉘 세션을 열어** 작업을 수행하는 컴포넌트임 | 5장 |

   이에 따라 당사는 1차 공문에서 전제한 "전산실에 두는 무거운 서버, 대수 산정, 랙 공간" 식의 일부 우려가 과도하였음을 인정합니다.

   **나. Tailscale의 용도**

   | 번호 | 당사가 이해한 내용 |
   | --- | --- |
   | 1 | 명세에 기술된 Tailscale은 **개발·테스트 단계의 임시 구성**임 |
   | 2 | 실제 운영 배포는 **웹 서비스↔실행기 간 mTLS**로 이루어지며, 내부망 대역은 **당사 관리자가 설정**함 |

   당사는 운영 배포가 Tailscale이 아닌 내부망 mTLS로 이루어지는 것으로 이해하였으며, 운영 설치 절차서를 이 기준으로 다시 제공하여 주실 것을 요청합니다(6항 참조).

5. 검토 결과 재정리

   **가. 보완 설명으로 완화·조정된 항목 (1차 공문 5항 다. 대비)**

   | 1차 우려 번호 | 1차 공문 내용 | 재통보 결과 |
   | --- | --- | --- |
   | 5 | 실행기 단일 구성, 이중화 방안 없음 | **등급 하향·재서술**. "실행기 서버 2대 증설"이 아니라 "실행기 컴포넌트 다중화·페일오버" 관점으로 재서술함. 다만 단일 컴포넌트 장애 시 운영 작업 실행이 멈추는 가용성 우려 자체는 유지함 (5항 다. 1번) |
   | 3 | 야간·주말 외부망 Tailscale 접속 시 내부망 판별 여부 | **대부분 해소**. 운영 배포가 내부망 mTLS 전제이므로 "Tailscale 접속의 내부망 판별"은 운영 단계의 쟁점이 아님. 단, 야간 당번의 내부망 접속 경로는 신규 확인 (5항 다. 2번) |

   아울러 1차 공문 제출 요청 자료 3번(실행기 권장 사양)과 관련하여, 실행기가 경량 컴포넌트라는 설명을 반영해 **"실행기 서버 대수·랙 공간" 전제를 철회**하되, 비용·사양 확인 자체는 **"실행기 컴포넌트 호스팅 자원"** 항목으로 유지합니다. 즉 해당 비용 항목을 삭제하지 않습니다.

   **나. 보완 설명과 무관하게 유지되는 필수 조건**

   아래 두 가지는 실행기의 성격 및 Tailscale 용도와 무관한 별개의 축이므로, 1차 공문의 필수 조건과 기한을 **그대로 유지**합니다. 하나라도 충족되지 않으면 평가 점수와 관계없이 도입하지 않습니다.

   | 번호 | 필수 조건 | 상태 | 유지 사유 |
   | --- | --- | --- | --- |
   | 1 | 감사 로그 파일 내보내기 (CSV 또는 엑셀) | **미충족·기한 불변** | 감사 로그 내보내기는 실행기의 실행 방식과 무관함. 1차 공문대로 **2026. 11. 24.(화)까지 시범 환경에서 실제 파일을 받아 내용을 확인하지 못하면 이번 도입 후보에서 제외**함 |
   | 2 | AI 분석 단계의 소스코드·데이터 흐름 공개 | **확인 불가** | 실행기가 "검증·복호화·웹쉘 로컬 실행" 컴포넌트라는 설명은 **실행 단계**에 관한 것임. 그 앞 단계인 **AI가 Plan을 분석·생성하는 단계**에서 소스코드·프롬프트가 어디로 전송·저장되는지는 별개 문제이므로 오히려 더 명확한 자료가 필요함 |
   | 3 | 승인 없는 실행 차단 | 검증 전 | 시범 기간 Plan 변조·서명 재사용 시험으로 직접 확인함 (붙임 2) |

   **다. 신규·유지 확인 항목**

   | 번호 | 내용 | 명세 근거 | 당사 확인 요청 |
   | --- | --- | --- | --- |
   | 1 | 실행기 컴포넌트 다중화·페일오버 | 5장 | 컴포넌트를 2개 이상 구성할 때 **nonce 소진 상태와 서명 검증 상태가 공유되는지**(동일 승인이 두 컴포넌트에서 이중 소진되지 않아야 함), 한쪽 장애 시 진행 중 요청이 유지되는지 |
   | 2 | 야간 당번 내부망 접속 경로 | 4.4 | Tailscale이 개발용으로 제외될 경우, 야간·주말 당번이 외부에서 내부망에 접속하는 경로(사내 VPN 등)와 그때 외부망 제한(`INTERNAL_NETWORK_ONLY`) 판별 방식 |
   | 3 | 내부망 대역 설정 권한·오류 영향 | 4.4, 4.5 | 당사 관리자가 내부망 대역을 설정하는 범위와, 설정 오류 시 외부망 제한 판별에 미치는 영향 |

   **라. 1차 공문에서 그대로 유지되는 그 외 우려**

   1차 공문 5항 다.의 우려 1(처리 시간 통계 없음), 2(일부 Plan 수정 시 전체 재승인), 4(`OWNER_MINIMUM` 대리 승인 부재), 6(PR·CI 연동 없음), 7(승인 화면 요약 없음), 8(퇴사자 키 폐기 절차), 9(한국어 지원 범위), 10(외부망 30분 만료 시 작성 내용 처리)은 이번 보완 설명의 영향을 받지 않으므로 **그대로 유지**합니다.

6. 요청 사항

   **가. 추가 자료 요청 (2026. 11. 20.(금)까지 공문 또는 메일 회신)**

   | 번호 | 요청 자료 | 요청 내용 |
   | --- | --- | --- |
   | 1 | 운영 배포용 설치 절차서 (내부망 mTLS 기준) | 명세의 Tailscale이 개발·테스트용임을 전제로, 운영 배포 시 웹 서비스↔실행기 mTLS 구성, 내부망 대역 설정 방법, 당사 관리자 설정 범위를 포함한 절차서 |
   | 2 | 실행기 컴포넌트 다중화 구성안 | 컴포넌트 다중화 시 nonce 소진·서명 검증 상태 공유 방식, 페일오버 동작, 진행 중 요청 처리, 필요한 호스팅 자원(기존 사내 호스트 활용 가능 여부 포함) |
   | 3 | AI 분석 단계 데이터 흐름 문서 (재확인) | 1차 공문 5항 가. 2번 요청의 재확인. "실행 단계"가 아닌 **"AI가 Plan을 분석·생성하는 단계"** 기준으로 소스코드·프롬프트 전송 위치(사내/귀사/제3자 AI 제공사), 저장 기간, 학습 사용 여부, 사내 설치형 분석 옵션 유무 |

   **나. 필수 요청 (기한 불변, 2026. 11. 24.(화)까지 실제 동작 확인)**

   1차 공문 5항 가. 1번(감사 로그 파일 내보내기)은 보완 설명과 무관하게 **기한과 조건이 변동 없습니다**. 제공 일정 회신만으로 충족으로 보지 않으며, 위 기한까지 시범 환경에서 실제 파일을 받아 내용을 확인하지 못하면 이번 도입 후보에서 제외합니다.

   **다. 시범 기간 시험 협조 (변동 없음)**

   1차 공문 붙임 2의 필수 시험 항목은 변동 없이 진행합니다. 다만 아래 항목을 보완 설명에 맞추어 조정합니다.

   | 시험 | 1차 공문 기준 | 재통보 조정 |
   | --- | --- | --- |
   | 외부망 배포 승인 제한 | Tailscale 접속 시 내부망 판별 확인 포함 | **내부망 mTLS 경로 기준**으로 `403 INTERNAL_NETWORK_ONLY` 판별을 확인. 시범 단계의 Tailscale 구성은 개발용으로만 사용 |
