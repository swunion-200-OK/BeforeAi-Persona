1. 귀사의 발전을 기원합니다.

2. 관련
   - 가. 귀사 서비스 소개 화상 미팅 (2026. 10. 28.(수))
   - 나. 귀사 제공 「API 명세서(기능 명세서 결정 사항 반영본)」 (이하 "명세")
   - 다. 당사 내부 도입 검토 회의 (2026. 11. 4.(수))

3. 당사는 웹 구축 외주와 자체 예약 관리 SaaS를 운영하는 임직원 28명(개발자 12명) 규모의 회사입니다. 2026. 10. 14.(수) AI 코딩 도구가 고객사 쇼핑몰 운영 DB에 검토되지 않은 쿼리를 실행해 주문 데이터 312건의 상태가 바뀌는 사고가 있었고, 이후 운영 DB 쓰기와 배포를 사람이 확인한 뒤 실행하도록 임시 조치하고 있습니다.

4. 위 관련 검토 결과, 당사는 귀사 서비스에 대해 **조건부 도입**을 결정하고 **무료 시범 사용**을 요청합니다. 이는 구매 확약이 아니며, 아래 5항 나.의 필수 조건 5개를 모두 충족하고 시범 결과가 당사 기준을 통과한 경우에만 당사 대표이사가 2026. 12. 4.(금) 최종 결재로 도입을 확정합니다. 필수 조건 중 하나라도 충족되지 않으면 도입하지 않습니다.

6. 요청 사항

   **가. 필수 요청 (5항 나.의 필수 조건 관련)**

   | 번호 | 요청 기능 | 요청 내용 |
   | --- | --- | --- |
   | 1 | 감사 로그 CSV 내려받기 | `GET /audit-logs/export?format=csv` 형태로, `GET /audit-logs`의 검색 조건(`actorId`, `departmentId`, `projectId`, `requestId`, `action`, `network`, `from`, `to`)을 그대로 적용. 승인자, 서명 키 ID, 접속 환경, IP, 검증 실패 항목 포함. 엑셀에서 한글이 깨지지 않을 것 (UTF-8 BOM 등). 내려받기 자체도 감사 로그에 남을 것 |
   | 2 | 조회 전용 역할 | 역할(1.3)에 예: `AUDITOR` 추가. `GET /audit-logs`, `GET /audit-logs/{logId}`, `GET /dashboard?scope=COMPANY`, `GET /requests` 조회만 허용하고, `/admin/*` 변경 API는 `403 FORBIDDEN_ROLE` |
   | 3 | `SMALL` 프리셋 규칙 공개 | 예: `GET /admin/policy/presets` 응답에 프리셋별·작업 유형별 `requiredApprovers.rule`과 `count`, 본인 승인 허용 범위, `PUT /admin/approval-matrix`로 조정 가능한 범위(담당자 최소 인원, `SAME_DEPT_OTHER` 대체 가능 여부) |
   | 4 | AI 분석 데이터 처리 문서와 외부 전송 통제 | 전송 항목, 외부 AI 제공업체와 재위탁 여부, 저장 위치·기간, 학습 사용 여부, 삭제 방식. 외부 전송을 끌 수 있는 설정이 있다면 그 API와 끈 경우의 기능 제한 |
   | 5 | 실행기 운영 문서 | 권장 사양, 업데이트 방법, 인증서·키 갱신 주기, 장애 시 동작(실행 중 작업 처리 포함), 백업·복구 절차, 귀사 지원 범위와 연락 창구 |

   | 4 | 웹 서비스 운영 주체(귀사 운영 또는 당사 설치), 당사 Tailscale 내부망 연결 구성과 접근 범위, 차단 책임, 추가 비용 | 2026. 11. 10.(화) |

   | 6 | 결제 연체 시 제한되는 기능 (킬 스위치 동작 여부 포함) | 2026. 11. 10.(화) |
   | 7 | 계약 해지·시범 종료 시 데이터 반환 형식, 기한, 삭제 확인 방법 | 2026. 11. 10.(화) |

   - 1~7번 회신이 2026. 11. 11.(수)까지 확인되지 않으면 당사는 이번 시범을 시작하지 않고 다른 방안을 검토합니다.

8. 회신 방법
   - 모든 회신은 공문 또는 메일로 해 주십시오. 구두 답변과 일정 미확정 답변은 검토에 반영하지 않습니다.
