1. 관련
   - 가. 우리 시 「AI 작업 통제 서비스(BeforeAI) 도입 검토 결과 통보 및 보완 자료 제출 요청」 (스마트도시정보과-4127, 2026. 11. 10.(화))
   - 나. 귀사 보완 설명 2건 (실행기 구조, Tailscale 구성) (2026. 11. 18.(수) 접수)
   - 다. 우리 시 보완 설명 검토 회의 (2026. 11. 20.(금))

2. 위 관련 나호로 귀사가 1차 검토에 대하여 보내 주신 보완 설명 2건을 검토한 결과를 다음과 같이 알려 드립니다. 보완 설명으로 우리 시가 오해하였던 부분은 정정하여 보류 사유 일부를 조정하였으나, **검토 결론은 보류를 유지**합니다. 아래 5항의 남는 필수 보완 요구는 관련 가호 공문의 제출 기한과 시험 일정을 그대로 두고 회신하여 주시기 바랍니다.

3. 검토 결론: **보류 유지 (보류 사유 일부 조정)**
   - 가. 귀사 보완 설명으로 **실행기의 성격**과 **Tailscale 구성**에 대한 우리 시의 보류 사유 일부를 조정하였으나, 검토 결론은 보류를 유지합니다.
   - 나. 보완 설명은 자료 설명이며, 보류 해제는 관련 가호 공문에서 정한 제출 자료(2026. 11. 27.·12. 11.)와 귀사 사무실 시험(2027. 1. 7.(목) 전후)으로 판단합니다. 설명만으로 보류를 해제하지 않습니다.
   - 다. 재검토 일정(2027. 1. 15.(금) 예산 요구 여부 판단, 2027. 6. 30.(수) 최종 재검토)과 계약·운영 도입 조건(필요한 인증·검증과 우리 시 보안성 검토 충족 후)은 관련 가호 공문과 같습니다. 변경이 없습니다.
   - 라. 이번 보완 설명 검토는 우리 시가 검토 대상 다른 업체에 보낸 공통 요구 기준표(관련 가호 공문 붙임 1)를 바꾸지 않습니다. 보완 설명 반영 내용은 귀사용 확인 자료에만 반영하였으며, 귀사에 대한 재검토 일정을 앞당기지 않습니다.

4. 보완 설명 검토 결과

   **가. 실행기의 성격 (오해 정정, 보류 사유 일부 조정)**

   - 1) 귀사 설명 요지: 실행기는 무거운 별도 인프라 러너가 아니라, (a) Plan 해시를 자체 생성하고 Ed25519 서명·nonce를 검증하는 서명 검증기, (b) 승인 envelope을 비대칭키 종단간 암호화(E2EE)로 받아 실행기 공개키로만 복호화하며 웹 서비스는 복호화할 수 없는 구성, (c) 검증 6단계 통과 시 해당 Plan 전용 웹쉘 세션으로 로컬 작업을 수행하는 경량 컴포넌트.
   - 2) 우리 시 정정 사항: 우리 시가 관련 가호 공문에서 실행기를 별도 서버 인프라로 보아 "서버 2대 이중화"를 전제한 부분을 정정합니다. 이중화 요구를 **"컴포넌트 다중화·페일오버"**로 다시 적습니다. 웹 서비스가 envelope을 복호화하지 못하는 점은 관련 가호 공문 4항 가. 2번으로 이미 강점으로 평가한 바와 같습니다.
   - 3) 그대로 유지하는 우려: 실행기가 경량 컴포넌트라는 점과, 검증 통과 후 **운영 서버에 웹쉘 세션이 열린다**는 점은 별개입니다. 따라서 관련 가호 공문 4항 다. 8번(웹쉘 세션)의 **명령 범위 제한과 세션 기록** 요구는 유지합니다. 컴포넌트 사양이 가벼워진다는 설명이 세션 권한 범위를 줄이는 것은 아닙니다.

   | 항목 | 1차 통보 시 전제 | 보완 설명 반영 후 |
   | --- | --- | --- |
   | 실행기 성격 | 별도 서버 인프라 러너로 이해 | 경량 서명 검증기 + E2EE 복호화 + 웹쉘 수행 컴포넌트로 재정의 |
   | 이중화 요구 | 실행기 서버 2대 | 컴포넌트 다중화·페일오버 (nonce 소진, 키 폐기, 정책 일관 반영은 시험으로 확인) |
   | 웹쉘 세션 | 명령 범위 제한·세션 기록 필요 | **유지** (경량 컴포넌트 여부와 무관) |

   **나. Tailscale 구성 (오해 정정, 보류 사유 일부 조정)**

   - 1) 귀사 설명 요지: Tailscale은 개발·테스트 단계의 임시 구성이며, 운영 배포는 고객사(우리 시) 내부망(행정망) 연결로 하고 웹 서비스 ↔ 실행기는 mTLS로 연결하며, 내부망 대역은 관리자가 설정하고, 운영 배포에 외부 조정 서버는 필요하지 않음.
   - 2) 우리 시 정정 사항: 관련 가호 공문 4항 나. 1번(행정망 내부 설치·통신 흐름)에서 "외부 조정 서버가 필요한 구성을 쓸 수 없음"으로 적은 부분을, **"귀사 설명대로 운영 배포가 행정망 내부 설치 + mTLS이고 외부 조정 서버가 없다면 상당 부분 해소되는 방향"**으로 조정합니다. 접속 환경 판별 대역(관련 가호 공문 4항 다. 9번)도 관리자 설정이 가능하다는 설명을 반영합니다.
   - 3) 해소로 보지 않고 시험으로 확인할 사항: "조정"은 설명에 대한 것이며 "해소"는 아닙니다. 다음을 2027. 1. 7.(목) 전후 시험과 제출 구성도로 확인한 뒤에 해당 사유를 내립니다.
     - 인터넷 연결을 전면 차단한 상태에서 **설치·라이선스 인증·알림·업데이트를 포함한 전체 운영**이 외부 통신 없이 정상 동작하는지
     - 내부망 대역을 관리자가 설정하여 **행정망 대역만 내부로 인식**하고 Tailscale 대역(100.64.0.0/10)과 그 밖의 대역을 외부로 처리하는지

   | 항목 | 1차 통보 시 전제 | 보완 설명 반영 후 |
   | --- | --- | --- |
   | 운영 배포 연결 | Tailscale 외부 조정 서버 전제라 불가 | 행정망 내부 설치 + mTLS, 외부 조정 서버 불요(귀사 설명) → 상당 부분 해소 방향 |
   | 판별 대역 | 100.64.0.0/10이 기본 내부망 | 관리자 설정으로 행정망만 내부 (시험으로 확인) |
   | 외부 통신 | 미확인 | 설치·라이선스·업데이트 포함 외부 통신 없음을 **시험·구성도로 확인 후 사유 해제** |

   **다. 보완 설명으로 조정되지 않는 사항**

   - 아래 사항은 실행기 구조·Tailscale 보완 설명과 무관하므로 그대로 유지합니다. 보완 설명으로 자동 해소되지 않으며, 증빙·명세·시험으로만 확인합니다. (5항에서 다시 정리)

5. 남는 필수 보완 요구 (보류 해제의 전제)

   - 아래 요구는 관련 가호 공문 5항 가.를 이어받아 다시 정리한 것입니다. 요구 기준표(붙임 1)와 제출 기한은 변경이 없습니다.

   | 번호 | 요구 기능 | 명세 근거 | 보완 설명으로 풀리지 않는 이유 |
   | --- | --- | --- | --- |
   | 1 | 검증필 암호모듈(KCMVP) 적용 | 2.4, 4.5, 5장 | 실행기가 경량이든 Tailscale을 빼든, 서명·암호화·mTLS에 쓰는 암호모듈의 검증 여부와 무관함. 모듈 제품명·버전·검증 범위 증빙이 필요함 |
   | 2 | 제품 인증(CC인증 또는 보안기능 확인서 등) | 명세 밖 | 구조 설명이 아니라 인증 보유·접수 증빙의 문제임 |
   | 3 | 공무원 승인권자 한정, 외주 인력 승인용 키 제출·등록 차단 | 1.3, 2.2, 3.1, 3.2, 5.1 | 역할에 소속 구분이 없는 상태가 그대로임 |
   | 4 | 외부망 접속·승인 전면 차단 | 1.1, 3.6, 4.4 | 운영 배포가 내부망이라는 설명과 별개로, 정책으로 외부망 기능을 끌 수 있어야 함 |
   | 5 | 감사 로그 2년 이상 보관, 파일 내보내기, 위변조 방지 | 3.9, 4.8 | 조회만 있는 상태가 그대로임 |

   | 8 | 승인자 본인 확인과 개인키 보호·회수 | 2.4, 3.1 | 구조 설명과 무관함 |

   - 위 8개 항목은 관련 가호 공문 5항 가. 필수 요청과 같은 취지입니다. 붙임 1 요구 기준표로 다른 업체에도 같이 요청한 내용이며, 이번 보완 설명으로 기준표를 바꾸지 않았습니다.

6. 회신 시 조정 요청 사항

   - 가. 관련 가호 공문 6항 제출 자료 5번 "서버 최소 사양과 이중화 지원 방식"을 **"컴포넌트 최소 사양과 다중화·페일오버 지원 방식(nonce 소진·키 폐기·정책 일관 반영 포함)"**으로 바꾸어 회신하여 주시기 바랍니다.
   - 나. 관련 가호 공문 6항 제출 자료 2번 "행정망 내부 설치 구성도와 전체 통신 흐름(설치, 라이선스 인증, 알림, 업데이트 포함)"에, 개발·테스트 구성과 운영 배포 구성을 **구분**하여 각각의 외부 통신 여부를 표시하여 주시기 바랍니다.
   - 다. 위 조정은 제출 기한(1차 2026. 11. 27.(금), 2차 2026. 12. 11.(금))과 시험 일정(2027. 1. 7.(목) 전후)을 바꾸지 않습니다.

7. 시험 확인 항목 (관련 가호 공문 5항 라. 시험에 추가)

   - 2027. 1. 7.(목) 전후 귀사 사무실 시험의 판정 항목에 다음을 추가합니다. 같은 항목을 다른 업체에도 같은 기준으로 적용합니다.
     - 가. 인터넷 연결 전면 차단 상태에서 설치·라이선스 인증·알림·업데이트를 포함한 운영이 외부 통신 없이 정상 동작하는지
     - 나. 내부망 대역 설정으로 행정망 대역만 내부로 인식하고 그 밖의 대역을 외부로 처리하는지
     - 다. 컴포넌트 다중화·페일오버 구성에서 nonce 소진, 키 폐기, 정책이 일관되게 반영되는지 (5.1, 3.2)
     - 라. 웹쉘 세션에서 수행 가능한 명령 범위와 세션 기록이 정책으로 설정·보관되는지 (5.1)
   - 관련 가호 공문에 포함한 Plan 변조(`PLAN_HASH_MISMATCH`), 서명 재전송(`NONCE_ALREADY_USED`), 폐기 키 사용(`KEY_NOT_REGISTERED`), 공무원 승인권자 한정, 외부망 차단, 사업자 계정의 정책·기록 단독 변경 불가 여부는 그대로 포함합니다.
   - 이 시험은 우리 시 행정망 적합성 판정을 대신하지 않으며, 미구현 기능은 미구현으로 기록합니다.

8. 회신 방법
   - 가. 모든 회신은 공문(전자문서 또는 우편)으로 하여 주시기 바랍니다. 구두 답변이나 일정이 확정되지 않은 답변은 검토에 반영하지 않습니다.
   - 나. 이번 공문은 관련 가호 공문을 대체하지 않으며, 보류 사유 조정과 회신 조정 요청만 추가한 것입니다. 관련 가호 공문 6항 제출 자료와 기한은 그대로 유효합니다.
   - 다. 기술 문의는 정보보안팀장 노재석(☎ 000-000-1231), 계약·예산·자료 문의는 정보화기획팀 주무관 배선영(☎ 000-000-1214)에게 하여 주시기 바랍니다. 면담은 우리 시 청사에서 2명 이상이 참석하여 진행하며 면담 기록을 남깁니다.
   - 라. 기한 내 제출이 어려운 항목은 기한 전에 사유와 제출 예정일을 공문으로 알려 주시기 바랍니다.
